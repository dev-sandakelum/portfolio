## Quick Facts

- **Framework:** Next.js 16.2.9 (App Router)
- **Runtime:** React 19
- **Styling:** Tailwind CSS v4 + CSS custom properties
- **Language:** TypeScript 5
- **3D:** React Three Fiber + Three.js (available, used for `pedestal.glb`)
- **Fonts:** Space Grotesk, JetBrains Mono, Inter (Google Fonts via `next/font`)
- **Deployment:** Standard Next.js build (`npm run build`)
