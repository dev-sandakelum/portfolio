## Cloud Computing යනු කුමක්ද?

**Cloud Computing** යනු internet ඔස්සේ computing resources (servers, storage, databases, networking, software) ලබා දීමේ ක්‍රමයකි. ඔබ භාවිතා කරන ප්‍රමාණයට පමණක් ගෙවීම සිදු කරයි.

## Microsoft Azure

**Azure** යනු Microsoft හි cloud computing platform එකයි. එය services 200කට වැඩි ප්‍රමාණයක් ලබා දෙයි.

## Azure හි ප්‍රධාන Services

### Compute Services

- **Virtual Machines (VMs)** — cloud තුළ virtual computers
- **App Service** — web apps host කිරීමට
- **Azure Functions** — serverless computing

### Storage Services

- **Blob Storage** — unstructured data සඳහා
- **SQL Database** — relational databases
- **Cosmos DB** — NoSQL database

## Azure Portal

Azure Portal යනු web-based management console එකකි. එය හරහා ඔබට:

- Resources create/manage කිරීම
- Monitoring සහ diagnostics
- Billing සහ cost management

> **ඉඟිය:** Azure free account එකක් create කර $200 free credit ලබා ගැනීමට Azure Portal වෙත පිවිසෙන්න.

## සාරාංශය

- Azure Microsoft හි cloud platform එකයි
- Services 200+ ක් ලබා දෙයි
- Pay-as-you-go pricing model
- Global data centers වලින් services ලබා දෙයි
